## 0. 설치 직후 — 여기서 막히면 아래는 볼 필요 없습니다

- [ ] 0-1 앱이 실행되고 첫 페이지가 뜬다
- [ ] 0-2 **실행 화면에서 3초 이상 멈추지 않는다** (광고 차단 규칙 컴파일 대기 지점)
- [ ] 0-3 이전 버전에서 열어 둔 탭과 페이지가 복원된다
- [ ] 0-4 **이전에 저장해 둔 즐겨찾기가 그대로 있다** (고급 메뉴 → `Favorites`)

0-4가 실패하면 즉시 멈추고 알려 주십시오. 저장 형식을 건드린 것이므로 되돌려야 합니다.

## 1. 리모컨 입력 — 가장 중요

쓰던 조작이 망가지는 쪽이 새 기능이 없는 쪽보다 나쁩니다.

- [ ] 1-1 터치면을 **가볍게 톡** → 커서 아래 요소가 **현재 탭**에서 즉시 반응
- [ ] 1-2 링크 위에서 **물리 클릭 1회** → **새 탭**에서 열림
- [ ] 1-3 물리 클릭 한 번에 탭이 **두 개 열리지 않음**
- [ ] 1-4 물리 클릭 **2회** → 커서 / 스크롤 모드 토글
- [ ] 1-5 커서를 크게 움직이다 손을 떼면 클릭되지 않음
- [ ] 1-6 PlayPause **1회** → 퀵 메뉴 / **2회** → 고급 메뉴
- [ ] 1-7 커서를 화면 최상단으로 올린 뒤 위 버튼 → 상단바 포커스 진입
- [ ] 1-8 상단바 포커스에서 좌우 이동 → 아이콘이 하나씩 이동하고 테두리 강조가 따라옴
- [ ] 1-9 상단바에서 아래로 내려오면 웹 화면 커서로 복귀

### 스크롤

- [ ] 1-10 방향패드 아래 / 위 → 한 화면씩 스크롤
- [ ] 1-11 방향패드 **길게 누르기** → 연속 스크롤, **떼면 즉시 정지**
- [ ] 1-12 커서를 화면 아래 가장자리에 대면 자동 스크롤, **손을 떼면 멈춤**
- [ ] 1-13 내부 컨테이너로 스크롤되는 사이트에서도 스크롤됨
- [ ] 1-14 스크롤이 버벅이거나 끊기지 않음

## 2. 뒤로 가기와 종료 — 이번에 바뀐 동작

- [ ] 2-1 링크를 몇 번 타고 들어간 뒤 **상단바 뒤로 가기** → **보고 있던 탭이** 한 단계 뒤로 간다
- [ ] 2-2 탭을 두 개 열어 두고 한쪽에서 뒤로 가기 → **다른 탭은 그대로** 있다
- [ ] 2-3 더 뒤로 갈 곳이 없을 때 뒤로 가기 → **`Exit App?` 확인창**이 뜬다
- [ ] 2-4 그 확인창에서 `Dismiss` → 앱이 그대로 유지된다
- [ ] 2-5 **Menu 버튼**도 2-1 ~ 2-3과 똑같이 동작한다
- [ ] 2-6 Alert나 메뉴가 떠 있을 때 Menu 버튼 → 뒤로 가지 않고 **그 창만 닫힌다**
- [ ] 2-7 동영상 전체화면에서 Menu 버튼 → 플레이어만 닫힌다

## 3. 종료 아이콘 — 새로 추가

- [ ] 3-1 상단바 **맨 왼쪽**에 전원 모양 아이콘이 있다
- [ ] 3-2 그 아이콘과 뒤로 가기 사이에 **얇은 구분선**이 보인다
- [ ] 3-3 아이콘을 선택 → `Exit App?` 확인창이 뜬다
- [ ] 3-4 `Exit` → 앱이 종료된다
- [ ] 3-5 다시 실행 → **탭과 설정이 유지된다** (종료 전에 저장함)
- [ ] 3-6 실수로 눌릴 만큼 뒤로 가기와 붙어 있지 않다

---

## 4. 상단바 아이콘 정리

- [ ] 4-1 아이콘들이 **같은 굵기·같은 크기**로 보인다 (예전처럼 들쭉날쭉하지 않다)
- [ ] 4-2 아이콘이 **깨지거나 빈칸으로 나오지 않는다**
- [ ] 4-3 왼쪽부터 순서: 종료 │ 뒤로 · 새로고침 · 앞으로 · 홈 · 탭
- [ ] 4-4 오른쪽: 로딩 표시 · 전체화면 · 메뉴
- [ ] 4-5 주소 표시줄 글자가 아이콘에 가리거나 잘리지 않는다
- [ ] 4-6 포커스를 옮길 때 강조 테두리가 아이콘 크기에 맞게 들어온다

4-2가 실패하면(아이콘이 빈칸) tvOS 버전에서 해당 심볼이 없는 것입니다. 어느 자리가 비었는지 알려 주시면 그 아이콘만 예전 그림으로 돌립니다.

## 7. 즐겨찾기 — 이번에 추가한 기능

- [ ] 7-1 0-4에서 확인한 기존 즐겨찾기가 여전히 그대로
- [ ] 7-2 아무 페이지에서 고급 메뉴 → `Add to Favorites` → 추가됨
- [ ] 7-3 같은 페이지에서 메뉴를 다시 열면 `Remove from Favorites`로 바뀌어 있음
- [ ] 7-4 그것을 선택 → 삭제되고 다시 `Add to Favorites`로 돌아옴
- [ ] 7-5 같은 페이지를 끝 `/`를 붙이거나 떼고 열어도 **같은 상태로 인식**
  - 예: `https://example.com` 과 `https://example.com/`
- [ ] 7-6 이미 즐겨찾기인 페이지를 `Favorites` → `Add Current Page`로 또 추가 → **중복이 생기지 않음**
- [ ] 7-7 기존 `Favorites` 메뉴의 목록 보기 / 선택해 이동 / 개별 삭제가 전처럼 동작
- [ ] 7-8 앱을 완전히 껐다 켜도 유지됨
- [ ] 7-9 빈 탭이나 로드 실패 페이지에서 메뉴 → **토글 항목이 보이지 않음**

## 9. 광고·콘텐츠 차단

- [ ] 9-1 고급 메뉴 → `Content Blocker Diagnostics`로 동작 경로 확인
  - **적어 두십시오**: 규칙 목록인지 JS 외형 차단인지에 따라 기대할 수 있는 수준이 다릅니다
  - `Failed: compile timed out`이 보이면 알려 주십시오 — tvOS에서 규칙 목록을 못 쓴다는 확정입니다
- [ ] 9-2 광고 많은 뉴스 사이트에서 광고가 줄어듦
- [ ] 9-3 끄고 새로고침하면 광고가 다시 보임
- [ ] 9-4 자주 쓰는 사이트 5곳에서 **레이아웃이 깨지거나 버튼이 사라지지 않음**
- [ ] 9-5 동영상 사이트 재생 정상
- [ ] 9-6 로그인 되는 사이트에서 로그인 정상

## 10. 읽기 모드

- [ ] 10-1 긴 기사에서 고급 메뉴 → `Reader Mode` → 본문이 큰 글씨로 깔끔하게 나옴
- [ ] 10-2 본문 중간 이미지가 남아 있고 크기가 적당함
- [ ] 10-3 **소제목이나 본문이 통째로 사라진 데가 없음** (요소 제거 규칙 확인)
- [ ] 10-4 방향패드로 **끝까지 스크롤됨**
- [ ] 10-5 메뉴 제목이 `Exit Reader Mode`로 바뀌어 있고, 선택하면 원래 페이지로 정확히 복원됨
- [ ] 10-6 본문이 거의 없는 페이지(검색 결과, 홈 화면)에서 실행 → **빈 화면 대신 안내 Alert**
- [ ] 10-7 강제 다크 모드를 **켠 상태로** 읽기 모드 진입 → 하얗게 반전되지 않음
- [ ] 10-8 읽기 모드에서 링크 클릭 → 이동하고 읽기 모드가 풀림
- [ ] 10-9 글자 크기를 키워 둔 상태에서 읽기 모드 → **글씨가 과하게 커지지 않음**
- [ ] 10-10 읽기 모드 상태로 탭을 바꿨다 돌아와도 문제없음
