## 1. 먼저 이것부터 — 사이트가 비는 문제 (2번 항목)

차단 선택자를 좁혔습니다. **이 절이 이번 판의 핵심입니다.**

- [ ] 1-1 유튜브 → **섬네일이 보인다**
- [ ] 1-2 네이버 뉴스 → 기사 목록과 본문이 정상
- [ ] 1-3 자주 쓰는 사이트 5곳에서 빈 영역이 없다
- [ ] 1-4 그래도 비어 보이면 **`방패 아이콘 → Content Blocking` 끄고 새로고침**
  - 정상이 되면 → 아직 차단 쪽. 어느 사이트인지 알려 주십시오
  - 그래도 비면 → 차단이 원인이 아님. 그때는 다른 데를 봅니다
- [ ] 1-5 광고는 여전히 줄어든다 (너무 느슨해지지 않았는지)

## 2. 리모컨 좌/우 = 뒤로/앞으로

- [ ] 2-1 왼쪽 클릭 → 전 페이지
- [ ] 2-2 오른쪽 클릭 → 다음 페이지
- [ ] 2-3 더 뒤로 갈 곳 없을 때 왼쪽 → 그 탭이 닫힌다
- [ ] 2-4 탭이 하나면 왼쪽 → 아무 일 없음
- [ ] 2-5 **상단바 포커스 중**에는 좌/우가 아이콘 이동으로 쓰인다 (뒤로 가지 않는다)
- [ ] 2-6 탭 오버뷰에서 좌/우가 탭 이동으로 쓰인다
- [ ] 2-7 메뉴가 떠 있을 때 좌/우가 메뉴 안에서 쓰인다
- [ ] 2-8 상/하 스크롤은 그대로
- [ ] 2-9 `기어 아이콘 → Left/Right for Back & Forward`로 끌 수 있다

2-5 ~ 2-7이 중요합니다. 좌/우를 가로챘기 때문에 다른 데서 쓰이던 자리를 침범하지 않았는지 봐야 합니다.

## 3. 상단바 포커스 가시성

- [ ] 3-1 포커스된 아이콘에 **흰 알약 모양 배경**이 들어온다
- [ ] 3-2 그 아이콘이 **어두운 색으로 바뀐다** (흰 배경 위라서)
- [ ] 3-3 아이콘이 약간 커진다
- [ ] 3-4 3미터에서 어디에 있는지 **한눈에 보인다**
- [ ] 3-5 좌우로 옮기면 알약이 따라온다
- [ ] 3-6 주소 표시줄에 포커스가 가도 똑같이 보인다
- [ ] 3-7 포커스를 빠져나오면 알약이 사라지고 아이콘이 흰색으로 돌아온다

## 4. 아이콘 4개 + 드롭다운

오른쪽, 왼→오 순서: 로딩 · **기어** · **방패** · **글자크기** · **별** · 전체화면 · ⋯

- [ ] 4-1 각 아이콘을 누르면 **그 아이콘 아래로 메뉴가 내려온다** (오른쪽에서 밀고 들어오지 않음)
- [ ] 4-2 **별** → 즐겨찾기 추가/해제, Favorites, History, 홈
- [ ] 4-3 **글자크기** → Reader Mode, 다크 모드 / Reader 글자 크기 / 페이지 글자 크기
- [ ] 4-4 **방패** → Content Blocking, 캐시 삭제, 쿠키 삭제, 차단 진단
- [ ] 4-5 **기어** → 리모컨·스크롤·페이지 설정, 사용 안내
- [ ] 4-6 **⋯** → 나머지(진단, 관리) 전부 그대로
- [ ] 4-7 맨 오른쪽 아이콘의 메뉴가 **화면을 벗어나지 않는다**
- [ ] 4-8 주소 표시줄이 짧아졌지만 주소를 읽을 수 있다
- [ ] 4-9 아이콘이 빈칸으로 나오지 않는다 (기어 / 방패 모양)

## 5. 읽기 모드 글자 크기

- [ ] 5-1 기본 크기가 전보다 크다 (52 → **68**)
- [ ] 5-2 소파에서 편하게 읽힌다
