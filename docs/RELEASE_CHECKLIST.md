# 릴리스 점검표 — v2.3.0

작업 7~12가 모두 main에 들어간 뒤, 릴리스를 만들기 전에 이 표를 기기에서 한 번 훑습니다.
항목마다 통과 / 실패를 적고, 실패가 하나라도 있으면 릴리스하지 않습니다.

빌드는 Actions의 **Build unsigned tvOS IPA**를 `publish_release = false`로 돌려 검증하고,
점검표를 모두 통과한 뒤에만 `publish_release = true`로 다시 돌립니다.

---

## 0. 릴리스 전 준비

- [ ] 작업 7~12가 모두 main에 반영되어 있다
- [ ] `publish_release = false`로 돌린 마지막 빌드가 성공했다
- [ ] `MARKETING_VERSION`과 `CURRENT_PROJECT_VERSION`을 올렸다
- [ ] 직전 릴리스 이후 커밋 목록을 훑어 빠진 작업이 없다

---

## 1. 기존 기능 회귀 — 가장 먼저 확인

새 기능보다 이쪽이 중요합니다. 쓰던 것이 망가지는 쪽이 새 기능이 없는 쪽보다 나쁩니다.

### 입력
- [ ] 터치면 가볍게 톡 → 커서 아래 요소가 **현재 탭**에서 즉시 반응
- [ ] 물리 클릭 1회(링크 위) → **새 탭**에서 열림
- [ ] 물리 클릭 한 번에 탭이 **두 개 열리지 않음**
- [ ] 물리 클릭 2회 → 커서 / 스크롤 모드 토글
- [ ] 커서를 크게 움직이다 손을 떼면 클릭되지 않음
- [ ] Menu 1회 → 뒤로 가기, 히스토리 없으면 종료 확인
- [ ] PlayPause 1회 → 퀵 메뉴 / 2회 → 고급 메뉴

### 스크롤
- [ ] 방향패드 아래 / 위 → 한 화면씩 스크롤
- [ ] 방향패드 길게 누르기 → 연속 스크롤, 떼면 정지
- [ ] 커서를 화면 아래 가장자리에 대고 있으면 자동 스크롤, **손을 떼면 멈춤**
- [ ] 커서를 화면 최상단으로 올린 뒤 위 버튼 → 상단바 포커스 진입
- [ ] 내부 컨테이너로 스크롤되는 사이트에서도 스크롤됨(JS 폴백)
- [ ] 스크롤이 버벅이지 않음

### 탭 · 내비게이션
- [ ] 탭 오버뷰 열기 / 전환 / 닫기
- [ ] 탭 5개까지 열리고, 6개째에 한도 알림이 뜨며 **페이지가 바뀌지 않음**
- [ ] 앱을 껐다 켜면 탭과 페이지가 복원됨
- [ ] 상단바 뒤로 / 앞으로 / 새로고침 / 홈 / 탭 / URL 입력

### 기타
- [ ] 동영상 재생(네이티브 플레이어 포함)
- [ ] 입력란 클릭 → 텍스트 입력 Alert → 값이 페이지에 반영됨
- [ ] 글자 크기 늘리기 / 줄이기 / 초기화
- [ ] 데스크톱 ↔ 모바일 User-Agent 전환
- [ ] 캐시 삭제 / 쿠키 삭제

## 2. 작업 7 — 다크 모드 강제

- [ ] 흰 배경 사이트에서 켜면 어두워짐
- [ ] 사진이 **색 반전 없이 정상**으로 보임
- [ ] 끄면 원래대로 돌아옴
- [ ] 켠 채 다른 페이지로 이동해도 적용됨
- [ ] 이미 어두운 사이트에서는 **밝아지지 않음**
- [ ] 동영상 색이 정상
- [ ] 읽기 모드 중에는 적용되지 않음
- [ ] 시작 페이지에는 적용되지 않음

## 3. 작업 8 — 광고·콘텐츠 차단

- [ ] 광고 많은 뉴스 사이트에서 광고가 줄어듦
- [ ] `Content Blocker Diagnostics`로 동작 경로 확인 (규칙 목록 / JS 외형 차단)
- [ ] 끄고 새로고침하면 광고가 다시 보임
- [ ] 자주 쓰는 사이트 5곳에서 **레이아웃이 깨지거나 버튼이 사라지지 않음**
- [ ] 동영상 사이트 재생 정상
- [ ] 로그인 되는 사이트에서 로그인 정상
- [ ] 탭 5개를 열어도 느려지지 않음

## 4. 작업 9 — 읽기 모드

- [ ] 긴 기사에서 켜면 본문이 큰 글씨로 나옴
- [ ] 본문 중간 이미지가 남아 있고 크기가 적당함
- [ ] 끝까지 스크롤됨
- [ ] 끄면 원래 페이지로 정확히 복원됨
- [ ] 본문이 거의 없는 페이지에서는 **빈 화면 대신 안내 Alert**
- [ ] 읽기 모드에서 링크 클릭 → 이동하고 읽기 모드가 풀림

## 5. 작업 10 — 즐겨찾기 설정/해제

- [ ] **기존에 저장해 둔 즐겨찾기가 그대로 있음** (가장 먼저 확인)
- [ ] `Add to Favorites` → 추가, 메뉴를 다시 열면 `Remove from Favorites`
- [ ] 삭제하면 다시 `Add to Favorites`
- [ ] 끝 `/` 유무와 상관없이 같은 페이지로 인식
- [ ] 같은 페이지를 두 번 추가해도 중복이 생기지 않음
- [ ] 기존 `Favorites` 메뉴의 목록 / 이동 / 개별 삭제 / 추가가 전처럼 동작
- [ ] 앱 재시작 후에도 유지

## 6. 작업 11 — 시작 페이지

- [ ] 홈 버튼 → 시작 페이지
- [ ] 타일이 저장된 즐겨찾기와 같은 개수·제목
- [ ] 타일 클릭 → 이동 / 꾹 눌러 클릭 → 새 탭
- [ ] 최근 방문 목록 동작
- [ ] 즐겨찾기가 없을 때 안내 문구
- [ ] 제목에 따옴표나 `&`가 든 즐겨찾기가 있어도 **화면이 깨지지 않음**
- [ ] 새 탭을 열면 시작 페이지가 뜸
- [ ] 토글을 끄면 원래 홈페이지로 감

## 7. 작업 12 — 링크 길게 눌러 메뉴

- [ ] 링크 위 길게 누르기 → 메뉴
- [ ] 새 탭에서 열기 / 이 탭에서 열기 / 즐겨찾기 추가·삭제 / 취소
- [ ] 메뉴에서 항목을 고른 뒤 **링크가 두 번 열리지 않음**
- [ ] `Cancel` 후 손을 떼도 아무것도 열리지 않음
- [ ] 링크가 아닌 곳에서 길게 누르면 메뉴가 뜨지 않고 평소대로 클릭됨
- [ ] 긴 URL에서 Alert가 화면을 벗어나지 않음
- [ ] 토글을 끄면 동작하지 않음

## 8. 마무리

- [ ] 고급 메뉴의 모든 토글을 한 번씩 켜고 꺼 봐서 앱이 죽지 않음
- [ ] 설정을 전부 켠 상태로 10분 정도 평소처럼 사용 — 느려지거나 멈추지 않음
- [ ] 앱을 강제 종료했다 다시 켜도 설정과 탭이 유지됨
- [ ] `MARKETING_VERSION`을 올렸다
- [ ] `publish_release = true`로 빌드해 릴리스 생성
- [ ] 받은 IPA의 SHA-256과 번들 버전을 확인
- [ ] 애플TV에 실제로 설치해 실행됨
