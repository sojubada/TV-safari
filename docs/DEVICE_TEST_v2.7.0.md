## 2. 읽기 모드 — 이번에 가장 중요

- [ ] 2-1 뉴스 기사에서 `AA → Reader Mode` → **본문이 가운데 좁은 단으로** 나온다
  (지난 사진처럼 화면 가득 차면 실패)
- [ ] 2-2 글자가 **확실히 크다** (기본 68)
- [ ] 2-3 위쪽에 여백이 있다 (상단바에 붙지 않는다)
- [ ] 2-4 배경이 어둡고 글자가 밝다
- [ ] 2-5 `Larger / Smaller Reader Text` → 즉시 반영
- [ ] 2-6 끄면 원래 페이지로 복원
- [ ] 2-7 **실패하면**: 안내창 문구를 알려 주십시오
  - `success:` 뒤에 숫자가 있으면 → 적용은 됐고 크기만 다름
  - 그 밖이면 → 추출 자체가 실패

2-1이 핵심입니다. 지난 사진은 추출은 됐는데 **꾸미기가 안 입혀진** 상태로 보였습니다.

## 3. 동영상 — 하얀 창

- [ ] 3-1 네이버 뉴스 동영상 클릭 → **하얀 새 탭이 열리지 않는다**
- [ ] 3-2 페이지 안에서 재생되거나, 최소한 **아무 일도 안 일어난다**
- [ ] 3-3 일반 링크 클릭은 여전히 새 탭에서 열린다
- [ ] 3-4 동영상 위에서 **가볍게 톡** → 현재 탭에서 반응

외부 플레이어 추적은 접었습니다. 여기서는 **새 탭이 동영상 클릭을 가로채지 않는 것**만 봅니다.

## 4. 유튜브

유튜브 캡처 훅을 **껐습니다**(기본값). 모든 페이지에서 `fetch`와 `XMLHttpRequest`를 가로채던 주입입니다.

- [ ] 4-1 유튜브 접속 → **화면이 그려진다** (백지가 아님)
- [ ] 4-2 섬네일이 보인다
- [ ] 4-3 안 되면 `기어 → User Agent`를 모바일로 바꾸고 다시
- [ ] 4-4 그래도 안 되면 `방패 → Content Blocking` 끄고 다시
- [ ] 4-5 **어느 단계에서 되었는지** 알려 주십시오 (안 됐으면 그것도)
