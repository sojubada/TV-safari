버전: 2.4.0 (빌드 3400) / 최소 tvOS 15.6

v2.3.0 목록(`DEVICE_TEST_v2.3.0.md`)은 그대로 유효합니다. 아래는 **이번에 바뀐 다섯 가지**만 봅니다.
실패한 번호만 알려 주시면 됩니다.

## 1. 짧은 클릭 / 긴 클릭 분리 — 이번의 핵심

- [ ] 1-1 동영상 위에서 **짧게 클릭** → **재생된다** (새 탭이 열리지 않는다)
- [ ] 1-2 링크 위에서 **짧게 클릭** → **현재 탭**에서 열린다
- [ ] 1-3 링크 위에서 **0.5초 이상 꾹 눌렀다 떼기** → **새 탭**에서 열린다
- [ ] 1-4 긴 클릭 한 번에 **탭이 두 개 열리지 않는다**
- [ ] 1-5 긴 클릭 후 **현재 탭이 그 링크로 이동해 있지 않다** (새 탭에서만 열려야 함)
- [ ] 1-6 터치면을 **가볍게 톡** → 현재 탭에서 즉시 반응 (예전과 같음)
- [ ] 1-7 **짧은 클릭 2회** → 커서 / 스크롤 모드 토글이 그대로 된다
- [ ] 1-8 0.4~0.5초 정도 애매하게 눌렀을 때 동작이 한 가지로만 일어난다
- [ ] 1-9 링크가 아닌 빈 곳에서 긴 클릭 → 아무 일도 일어나지 않는다
- [ ] 1-10 입력란에서 짧게 클릭 → 텍스트 입력 Alert가 뜬다

1-1이 이번 변경의 이유입니다. 전에는 동영상을 눌러도 "새 탭에서 열기"가 먼저 가로채 재생이 묻혔습니다.

## 2. 뒤로 가기 → 탭 닫기

- [ ] 2-1 링크를 몇 번 타고 들어간 뒤 **Menu 버튼** → 한 단계 뒤로
- [ ] 2-2 더 뒤로 갈 곳이 없을 때 Menu → **그 탭이 닫히고** 다른 탭이 보인다
- [ ] 2-3 **탭이 하나뿐일 때** 더 뒤로 갈 곳 없이 Menu → **아무 일도 일어나지 않는다**
  - 종료 확인창이 더 이상 뜨지 않습니다. 의도된 변경입니다
- [ ] 2-4 상단바 **뒤로 가기 아이콘**도 2-1 ~ 2-3과 똑같이 동작한다
- [ ] 2-5 Alert나 메뉴가 떠 있을 때 Menu → 그 창만 닫힌다
- [ ] 2-6 종료는 상단바 **맨 왼쪽 전원 아이콘**으로 여전히 된다

## 3. 웹 동영상 전체화면에서 빠져나오기

- [ ] 3-1 웹 플레이어(유튜브 등)를 **웹 자체 전체화면**으로 만든 뒤 Menu → 전체화면만 빠져나온다
- [ ] 3-2 그 상태에서 Menu를 한 번 더 → 그때 뒤로 가기가 동작한다
- [ ] 3-3 전체화면이 **아닐 때** Menu → 바로 뒤로 간다 (멈칫하지 않는다)
- [ ] 3-4 네이티브 플레이어(앱이 띄우는 전체화면)에서 Menu → 예전처럼 플레이어가 닫힌다

3-1이 안 되면 그 사이트가 쓰는 전체화면 방식이 다른 것입니다. **어느 사이트인지** 알려 주십시오.

## 4. 커서 자동 숨김

- [ ] 4-1 손을 떼고 **3초** 두면 커서가 부드럽게 사라진다
- [ ] 4-2 터치면을 만지거나 버튼을 누르면 **즉시 다시 나타난다**
- [ ] 4-3 동영상을 볼 때 커서가 화면을 가리지 않는다
- [ ] 4-4 커서가 사라진 상태에서 **짧게 클릭** → 엉뚱한 곳이 눌리지 않는다
  (커서 위치는 그대로 유지되어야 합니다)
- [ ] 4-5 스크롤 모드로 바꿨다 커서 모드로 돌아오면 커서가 보인다
- [ ] 4-6 탭 오버뷰를 열었다 닫아도 커서가 정상으로 보인다
- [ ] 4-7 커서가 사라지는 동작이 스크롤을 방해하지 않는다

## 5. 배경색

- [ ] 5-1 배경을 직접 칠하지 않는 사이트에서 **검은 바탕이 보이지 않는다**
- [ ] 5-2 페이지가 바뀔 때 깜빡임이 거슬리지 않는다
- [ ] 5-3 **강제 다크 모드를 켠 상태**에서 페이지 이동 → 흰 화면이 번쩍이지 않는지 확인
  - 번쩍인다면 알려 주십시오. 다크 모드일 때만 배경을 어둡게 두는 쪽으로 바꾸겠습니다
