## 1. 네이버 뉴스 동영상 — 검은 화면

고친 것은 **재생이 아니라 진단**입니다. 검은 화면으로 방치되지 않고 원인을 말해 줍니다.

- [ ] 1-1 네이버 뉴스 동영상 클릭 → **6초 안에** 재생되거나 **안내창**이 뜬다 (검은 화면으로 남지 않음)
- [ ] 1-2 안내창이 떴다면 **적힌 문구를 알려 주십시오** — 여기서 원인이 갈립니다
  - "produced no picture" → 코덱이나 DRM. 외부 플레이어로는 어려움
  - 그 밖의 문장 → AVPlayer 오류 메시지. 그 내용으로 좁힐 수 있습니다
- [ ] 1-3 안내창에서 `Use In-Page Playback` → 그 뒤 동영상 클릭 시 **페이지가 직접 재생**한다
- [ ] 1-4 `Keep External Player` → 설정이 그대로 유지된다
- [ ] 1-5 정상 재생되는 동영상에서는 **안내창이 뜨지 않는다** (오탐 확인)
- [ ] 1-6 유튜브 동영상도 1-1처럼 동작한다
- [ ] 1-7 재생 중 Menu → 플레이어가 닫히고 원래 페이지로 (v2.4.0 동작 유지)

1-2가 이번 핵심입니다. 그 한 줄로 다음에 무엇을 고칠지 결정됩니다.

## 2. 새 탭 열기 — 클릭으로 되돌림

- [ ] 2-1 링크 위에서 **물리 클릭** → **새 탭**에서 열린다
- [ ] 2-2 링크 위에서 **가볍게 톡** → **현재 탭**에서 열린다
- [ ] 2-3 클릭을 **길게 눌렀다 떼도** 새 탭에서 열린다 (누르는 시간 무관)
- [ ] 2-4 클릭 한 번에 탭이 **두 개 열리지 않는다**
- [ ] 2-5 클릭 후 **현재 탭이 그 링크로 이동해 있지 않다**
- [ ] 2-6 클릭 **2회** → 커서 / 스크롤 모드 토글
- [ ] 2-7 동영상 위에서 클릭 → **재생된다** (새 탭이 열리지 않는다)

2-7이 중요합니다. 동영상 판정이 새 탭보다 먼저라서 영향이 없어야 합니다.

## 3. 상단바 아이콘 두 개 추가

오른쪽, 메뉴(⋯) 왼쪽에 들어갔습니다. 왼→오: 로딩 · **글자크기** · **별** · 전체화면 · 메뉴

- [ ] 3-1 **별 아이콘** → `Favorites & History` 메뉴
  - 즐겨찾기 추가/해제, Favorites 목록, History, 홈으로, 현재 페이지를 홈으로
- [ ] 3-2 **글자크기 아이콘** → `Reading` 메뉴
  - Reader Mode, Force Dark Mode / 글자 크게·작게·초기화, Page Scaling
- [ ] 3-3 두 메뉴의 항목이 고급 메뉴에 있던 것과 **같은 문구·같은 동작**
- [ ] 3-4 고급 메뉴(⋯)에도 그 항목들이 **그대로 남아 있다**
- [ ] 3-5 아이콘이 깨지거나 빈칸이 아니다 (별 / 글자크기 모양)
- [ ] 3-6 상단바 포커스에서 좌우로 새 아이콘까지 이동된다
- [ ] 3-7 주소 표시줄 글자가 아이콘에 가리거나 잘리지 않는다
- [ ] 3-8 URL이 없는 빈 탭에서 별 아이콘 → 즐겨찾기 토글 항목만 빠지고 나머지는 보인다

## 4. 읽기 모드 글자 크기

- [ ] 4-1 **소파에서** 긴 기사를 읽기 모드로 → 편하게 읽힌다
- [ ] 4-2 한 줄이 너무 길거나 너무 짧지 않다 (한글 25~30자쯤)
- [ ] 4-3 제목이 본문보다 분명히 크다
- [ ] 4-4 소제목이 본문과 구분된다
- [ ] 4-5 이미지가 본문 폭에 맞고 위아래 여백이 적당하다
- [ ] 4-6 끝까지 스크롤되고 **마지막 문단이 화면 아래에 걸리지 않는다**
- [ ] 4-7 글자 크기 설정을 키워 둔 상태에서도 읽기 모드는 일정하다
- [ ] 4-8 여전히 작거나 너무 크면 **어느 쪽인지** 알려 주십시오 (수치로 조정합니다)

현재 값: 본문 52px / 제목 68px / 소제목 58px / 단 폭 1500px.
55인치 3미터 기준으로 본문 글자 높이가 약 26각분이 되도록 잡았습니다. Apple의 TV 최소 권장이 29pt인데 이전 34px이 그 근처라 "보이긴 하지만 오래 읽기 힘든" 크기였습니다.
